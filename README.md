# BTENERGY — версия для публикации

Весь сайт находится в index.html: стили, JavaScript, иконки и фотографии встроены в файл. Папка assets и сборка не требуются.

Откройте index.html в браузере либо разместите файл в каталоге сайта веб-сервера.

Источники фотографий производителей указаны под фотографиями на странице: Loxone и Яндекс. Другие фотографии встроены из исходного макета.

## Облегчённая версия

index-lite.html — версия с отдельными изображениями WebP в папке web-assets. Для публикации скопируйте index-lite.html как index.html, а web-assets разместите рядом. Исходная версия со встроенными фотографиями сохранена в index.html.
